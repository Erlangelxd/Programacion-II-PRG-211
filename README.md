Repositorio de apoyo académico para la materia **Programación II** de la carrera de **Ingeniería de Sistemas**.

Aquí se almacenan los ejemplos, ejercicios, prácticas y soluciones desarrolladas durante las sesiones de auxiliatura, con el objetivo de reforzar los conceptos vistos en clases y proporcionar material de consulta para los estudiantes.

---

## Objetivos

- Reforzar los conocimientos adquiridos en la materia.
- Proporcionar ejemplos prácticos y explicados.
- Facilitar la resolución de ejercicios y prácticas.
- Promover buenas prácticas de programación.
- Servir como material de estudio antes de evaluaciones y exámenes.

---

## Temas abordados

Dependiendo del avance de la materia, el repositorio puede incluir:

- Introduccion a programación orientada a objetos
- Abstraccion
- Polimorfismo
- Encapsulacion
- Herencia
- Persistencia y concurrencia
- Patrones de diseño
---

## Clonar el repositorio

Para obtener una copia local del repositorio:

```bash
git clone https://github.com/Erlangelxd/Auxiliatura-de-programacion-II-.git
```

Ingresar al directorio:

```bash
cd Auxiliatura-de-programacion-II-
```

---

## ¿Cómo utilizar este repositorio?

1. Revisar la teoría correspondiente al tema.
2. Analizar los ejemplos desarrollados.
3. Intentar resolver los ejercicios por cuenta propia.
4. Comparar la solución personal con la propuesta.
5. Realizar modificaciones para comprender mejor el funcionamiento del código.

- Tener instalado Git (opcional)
